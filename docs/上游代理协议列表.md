# mihomo 支持的上游代理协议列表

本文说明 mihomo 在 `proxies:` 中作为出站节点时，当前代码实际支持哪些 `type`。

结论以当前仓库的解析器为准：

- [adapter/parser.go](/vm/project/github/clash-meta/mihomo/adapter/parser.go:12)

## 1. 可连接远端服务器的协议

下面这些 `type` 都会建立到远端服务器或远端隧道的连接。

| `type` | 说明 |
|---|---|
| `socks5` | SOCKS5 代理 |
| `http` | HTTP/HTTPS 代理 |
| `ss` | Shadowsocks |
| `ssr` | ShadowsocksR |
| `vmess` | VMess |
| `vless` | VLESS |
| `snell` | Snell |
| `trojan` | Trojan |
| `hysteria` | Hysteria |
| `hysteria2` | Hysteria2 |
| `wireguard` | WireGuard |
| `tuic` | TUIC |
| `ssh` | SSH |
| `mieru` | Mieru |
| `anytls` | AnyTLS |
| `sudoku` | Sudoku |
| `masque` | MASQUE |
| `trusttunnel` | TrustTunnel |

如果你只是想确认“像 `socks5` 这样的常见上游代理协议有哪些”，最常见的是这几类：

- `socks5`
- `http`
- `ss`
- `ssr`
- `vmess`
- `vless`
- `trojan`
- `snell`
- `hysteria`
- `hysteria2`
- `wireguard`
- `tuic`
- `ssh`

## 2. 特殊出站类型

下面这些 `type` 也能出现在 `proxies:` 中，但它们不是“连接远端代理服务器”的协议：

| `type` | 说明 |
|---|---|
| `direct` | 直连 |
| `dns` | 走 DNS 出站适配器 |
| `reject` | 拒绝连接 |

因此，如果你的问题是“连接代理服务器时都支持哪些协议”，通常不把这三个算进协议列表。

## 3. 代理组不是协议

`proxy-groups:` 里的这些类型不是上游协议，而是节点调度策略：

- `select`
- `url-test`
- `fallback`
- `load-balance`

对应解析位置：

- [adapter/outboundgroup/parser.go](/vm/project/github/clash-meta/mihomo/adapter/outboundgroup/parser.go:154)
